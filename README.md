# javascript-modern-lab-2

Lucrare de laborator — JavaScript modern (module, array methods, destructuring, spread).

## Structură
```
javascript-modern-lab-2/
├── task-01/   # filter, map, reduce pe un array de note
├── task-02/   # module utils.js + students.js + main.js, elevi
├── task-03/   # modul coș de cumpărături
└── README.md
```

## Rulare
Fiecare task se rulează cu Node.js (necesită Node 14+ pentru module ES):
```
cd task-01
node index.js
```
```
cd task-02
node main.js
```
```
cd task-03
node main.js
```
